# **App Name**: ResumeSpark AI

## Core Features:

- Template Selection: Allow students to browse and select from 4 predefined, professional resume templates as a starting point for their resume.
- AI Content Generator: Utilize AI to suggest or generate content (e.g., summary statements, bullet points for experience/education) based on user-provided keywords and job descriptions as a tool for quick drafting.
- Intuitive Resume Editor: Provide a user-friendly interface for students to input, edit, and arrange their personal information, education, work experience, skills, and other relevant resume sections.
- Real-time Preview: Display a real-time preview of the resume, showing how entered data fits into the chosen template, updating as the user edits.
- Download PDF: Enable users to download their completed resume in a professional PDF format, ready for submission.
- Temporary Data Management: Securely store user resume data temporarily for up to 2 minutes in session storage or similar, ensuring no persistent database is required as per request.

## Style Guidelines:

- A vibrant cyan (#00BCD4) conveying freshness and innovation, offering good contrast against a light background.
- A subtle, light cool-grey (#F0F2F5) providing a clean and understated canvas for resume content.
- A slightly darker, energetic teal (#0097A7) to highlight key actions and AI-driven elements, injecting a contemporary and intelligent feel.
- Headlines and section titles will use 'Space Grotesk' (sans-serif) for a modern, tech-inspired touch. Body text and longer descriptions will use 'Inter' (sans-serif) for its high readability and objective feel.
- Employ clean, minimalistic line-art icons that complement the professional aesthetic and clearly represent different resume sections (e.g., education, experience, contact).
- A responsive, two-column layout is recommended: one for data input/editing forms and the other for the real-time resume preview. Sections should be clearly delineated and navigable.
- Subtle, fluid animations will guide the user through different stages of resume creation, such as switching between templates or updating the preview, enhancing the user experience without distraction.
